<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| views → state/apply.js | Single chokepoint that owns transactional integrity |
| state/apply.js → BroadcastChannel | Cross-tab message MUST fire AFTER tx commit, NEVER before |
| BroadcastChannel('habits') | Same-origin pub/sub — browser enforces origin |
| visibilitychange handler → IDB flush | Mobile lifecycle hook; `beforeunload` is forbidden |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-10 | Tampering | Out-of-order broadcast | mitigate | `apply.js` MUST `await runTx(...)` (returns only after `tx.oncomplete`) THEN call `broadcast(...)` per RESEARCH §Pattern 4 line 482 + Pitfall 2. Integration test asserts ordering via a fake-BC hook that records the post-commit timestamp. |
| T-02-11 | Information Disclosure | Broadcast leaks user content | mitigate | Broadcast payload carries `{keys: {habitId, date, ...}}` ONLY — never the new row values (Pitfall 8 + RESEARCH §Pattern 5). Receiver re-reads from IDB. Integration test asserts the broadcast object contains no `value`/`completed`/`row` field. |
| T-02-12 | Tampering | Undo token desync | mitigate | Every `apply()` call MUST write `meta.undoToken = eventRow.id` in the SAME tx as the data row(s) (D-43, Pitfall 7). If a future non-undoable event ships in P3+, it MUST write `meta.undoToken = null` — banned in P2's `markCompleted` (always undoable). |
| T-02-13 | Tampering | beforeunload flush attempt | mitigate | `js/platform/lifecycle.js` MUST NOT contain the literal substring `beforeunload`. Grep gate in the discipline test (`tests/unit/apply.discipline.test.js`). MDN explicitly recommends against; D-08/Pitfall 8 reject. |
| T-02-14 | Tampering | Views bypass apply.js | mitigate | `tests/unit/apply.discipline.test.js` greps every file under `js/views/`, `js/io/`, and `js/state/undo.js` for direct `js/db/repo.js` writes (`putHabit`, `putLog`, `putEvent`, `putMeta`, `putSetting`) — any match outside `js/state/apply*.js` is a violation (Anti-Pattern 1 enforcement). |
| T-02-15 | Spoofing | Cross-origin BC tampering | accept | Browser enforces same-origin BroadcastChannel. No additional defense needed (RESEARCH §Security Domain). |
</threat_model>
