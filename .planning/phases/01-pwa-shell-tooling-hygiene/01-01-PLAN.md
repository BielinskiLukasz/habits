## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Disk → browser | User opens `icon.svg` / `manifest.json` directly from disk via `file://`; static asset only, no executable code path |
| Browser → manifest install pipeline | OS install pipeline ingests `manifest.json` + `icon.svg` to register the PWA; the manifest is the trust boundary for install configuration |
| Repo → static-host CDN (GitHub Pages) | The bytes shipped from this repo become the production app; no transformation pipeline means the source IS the binary |
