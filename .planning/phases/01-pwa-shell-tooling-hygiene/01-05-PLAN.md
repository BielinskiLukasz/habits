## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| README documentation → developer behavior | The README is the contract between the codebase and any future developer (or the same author later); inaccuracies become tampering vectors (wrong APP_VERSION procedure → stale cache; missing static-gate doc → drift in NFR compliance) |
| GitHub Pages deploy → production users | Pushing to `main` ships to the only production URL; the trailing-slash convention is the only deployment-time gotcha |
| Real-device install pipeline → OS PWA registration | The phase-gate confirms the manifest + sw.js + icon ship correctly to Android / iOS / desktop install pipelines |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-V14 (documentation) | Tampering | `README.md` deploy section | mitigate | The trailing-slash convention for GH Pages is documented prominently per Pitfall 3, mitigating the silent SW-scope misresolution that would otherwise break installs on `/habits` (no trailing slash) deployments. |
| T-01-StaleCache (procedure) | Tampering | `README.md` version-bump section | mitigate | Explicit procedure for bumping APP_VERSION in `js/util/version.js`, plus the D-10 rule (bump only on shell-asset changes). Prevents the "I forgot to bump" stale-cache failure mode. |
| T-01-ResetSurface (discoverability) | Repudiation | `README.md` recovery section | mitigate | The Reset-shell recovery path is documented with verbatim D-06 phrasing AND both trigger paths (?debug=1, long-press). Future developers can recover from a broken SW deploy without needing to read the source. |
| T-01-NoNet (audit gate) | Information Disclosure | `README.md` static-gates section | mitigate | The NFR-04 grep gate is documented for easy re-run. If a later phase accidentally introduces `fetch('https://…')`, the gate catches it immediately. |
