## Context

### Schema Resolution: score_snapshots keyPath Conflict

`js/db/schema.js` declares `score_snapshots` with `keyPath: ['habitId', 'date']`. This allows **one row per (habitId, date)**. D-113 originally said "3 rows per (habit, date) — one per model," but that would require a compound keyPath of `['habitId', 'date', 'model']` which conflicts with the locked v1 schema.

**Resolution (locked for all P6 plans):** Each `score_snapshots` row holds all three model results in a single row. The actual row shape is:

```
{
  habitId: string,
  date: string,          // YYYY-MM-DD (keyPath field)
  s1Score: number,       // 0–100 rolling completion %
  s1Status: 'Healthy'|'Watch'|'At-risk'|'Failing'|null,
  s2Score: number,       // 0–1 weighted score
  s3Score: number,       // 0–1 load-adjusted score
  scoreVersion: number,  // always 1 for P6
}
```

No `model` field in the keyPath. Views filter/display the appropriate score column based on `settings.scoringModel`.

### Scoring Model Specs (D-110, D-111, D-112)

**S1 (Rolling Threshold Health):**
- `s1Score` = `completedCount / applicableDayCount * 100` over rolling window (default 70 days)
- `s1Status`: Healthy ≥ globalThreshold (default 90%), Watch 70–threshold, At-risk 50–70, Failing < 50
- Grace period (7 days): return `{s1Score: null, s1Status: null}` — habit excluded
- Mastered habits: `s1Score = 100`, `s1Status = 'Healthy'` (0.3× weighting means always healthy)
- Cadence-aware denominator: count only applicable days (reuse `ctx.appliesToday`)

**S2 (Day-Weighted Wave Score, D-111):**
- Exponential weighting: `weight(d) = 2^(-d/21)` where d = days ago (0 = today)
- Weighted score = `Σ(weight(d) × completed(d)) / Σ(weight(d) × applicable(d))` over rolling window
- Stage multiplier applied to numerator only: etap1=1.0, etap2=1.25, etap3=1.5 (habit.stage field)
- Mastered habits: weight entire habit at 0.3× (multiply both numerator and denominator weights by 0.3)
- Grace period: return `s2Score: null` for habits < 7 days old
- Result is 0–1 (NOT 0–100); normalize at end

**S3 (Load-Adjusted Capacity Score, D-112):**
- Per day: `s3DayScore(habit, day) = completed(day) / applicableHabitsOnDay`
  where `applicableHabitsOnDay` = count of ALL applicable habits on that day (the "load")
- Mastered habits count as always-completed (contribute 0.3 to numerator automatically on applicable days)
- Per-habit S3 = sum of s3DayScore contributions over rolling window, then normalize to [0, 1]
- Grace period: return `s3Score: null`
- `computeS3` receives `allHabits` (array) so it can compute the daily load denominator

### Shared constraints:
- All three models reuse `ctx.appliesToday(habit, dateYMD, ctx)` from `js/domain/cadence.js` (injected via ctx, NOT imported directly — keeps scoring.js Node-testable with a mock)
- `ctx.windowDays` = rolling window (default 70 days)
- `ctx.globalThreshold` = mastery threshold % (default 90)
- `isInGracePeriod` imported from `js/util/date.js`
- `daysFrom` imported from `js/util/date.js`

### T2: GREEN — Implement js/domain/scoring.js

**Type:** feat
**Files:**
- [new] `js/domain/scoring.js` — the three pure scoring functions

**Implementation spec:**

File header: `/** @file Pure scoring model functions S1/S2/S3 (SCORING-01..07, D-110..D-112, D-114). Called only by js/io/scoreSnapshots.js — never by views. No IDB calls. */`

Export three functions with the following signatures and behavior:

**`computeS1(habit, logsForHabit, ctx)`**
- Import `isInGracePeriod`, `daysFrom` from `../util/date.js`
- If `isInGracePeriod(habit.createdAt, ctx.evaluationDate)` → return `{s1Score: null, s1Status: null}`
- If `habit.isMastered === true` → return `{s1Score: 100, s1Status: 'Healthy'}`
- Count applicable days in `[windowStart, ctx.evaluationDate]` using `ctx.appliesToday`
  - `windowStart = daysFrom(ctx.evaluationDate, -(ctx.windowDays - 1))`
- Count completed days from `logsForHabit` within the window (same LOG_COMPLETED dispatch as mastery.js)
- `s1Score = Math.round(completedCount / applicableDayCount * 100)` — returns 0 if applicableDayCount === 0
- `s1Status`: Healthy if s1Score >= ctx.globalThreshold; Watch if 70 <= s1Score < ctx.globalThreshold; At-risk if 50 <= s1Score < 70; Failing if s1Score < 50
- Returns `{s1Score, s1Status}`

**`computeS2(habit, logsForHabit, ctx)`**
- If `isInGracePeriod(habit.createdAt, ctx.evaluationDate)` → return `{s2Score: null}`
- Stage multiplier: `stageMultiplier = {1: 1.0, 2: 1.25, 3: 1.5}[habit.stage] ?? 1.0`
- Base weight multiplier: `habit.isMastered ? 0.3 : 1.0`
- For each day i from 0 to ctx.windowDays-1 (i=0 is today, i=ctx.windowDays-1 is oldest):
  - `dayYMD = daysFrom(ctx.evaluationDate, -i)`
  - `w = Math.pow(2, -i / 21) * baseWeightMultiplier`
  - If `ctx.appliesToday(habit, dayYMD, ctx)`:
    - `denominator += w`
    - log = logsForHabit.find(l => l.date === dayYMD)
    - If log is completed (per LOG_COMPLETED dispatch): `numerator += w * stageMultiplier`
- `s2Score = denominator > 0 ? numerator / denominator : 0` — clamp to [0, 1]
- Returns `{s2Score}`

**`computeS3(habit, logsForHabit, ctx, allHabits)`**
- If `isInGracePeriod(habit.createdAt, ctx.evaluationDate)` → return `{s3Score: null}`
- `windowStart = daysFrom(ctx.evaluationDate, -(ctx.windowDays - 1))`
- Accumulate s3Score over the window:
  - For each day i in 0..ctx.windowDays-1:
    - `dayYMD = daysFrom(ctx.evaluationDate, -i)`
    - `loadCount = allHabits.filter(h => ctx.appliesToday(h, dayYMD, ctx)).length`
    - If loadCount === 0: skip day
    - If habit does not apply on dayYMD: skip day
    - Determine completed:
      - If `habit.isMastered === true`: completed contribution = 0.3
      - Else: find log for dayYMD, use LOG_COMPLETED dispatch → 1 if completed, 0 if not
    - `dayContrib = completedContrib / loadCount`
    - `rawSum += dayContrib`
    - `applicableDays += 1`
- `s3Score = applicableDays > 0 ? Math.min(1, rawSum / applicableDays) : 0`
- Returns `{s3Score}`

**LOG_COMPLETED dispatch table** (same as mastery.js, do NOT import from mastery.js — keep scoring.js self-contained):
```
binary: log.completed === true
numeric: (log.count ?? 0) >= (habit.target ?? 1)
slot-checklist: log.slots?.every(s => s.checked) && log.slots.length > 0
```

Note: `ctx.evaluationDate` is the YYYY-MM-DD string passed by the snapshot writer (usually "today" for write-time snapshots, or a specific date for bulk recompute).
