    - await _repo.getAllHabits() to read all habits
    - filter: status === 'scheduled' AND startDate <= todayLocal()
    - if none, return early
    - await _repo.runTx(['habits'],'readwrite', body) — for each affected habit, tx.objectStore('habits').put({...habit, status:'active'})
