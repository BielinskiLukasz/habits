<objective>
Fix four stale-boolean callers that break wave analytics, scoring, backup import, and lastCompletedDate tracking for any log written after the Phase 11 4-state model migration.

Purpose: The 4-state log model (Phase 11) replaced `completed: boolean` with `status: string`. Four production call-sites still check the old boolean. These silently return wrong data — wave completion rates show 0, streaks are empty, old backups import without state, and lastCompletedDate can be stranded. These bugs must be confirmed by RED tests before any code change.

Output: A failing test file (RED commit), then two GREEN commits — one for the boolean-swap fixes in waveAggregates.js + import.js, one for the architectural addition to markSkipped.js.

Note: js/io/scoreSnapshots.js was already patched in commit 0dbd185 (binary completion check aligned to 4-state model). The plan verifies that fix is intact but does not write a separate RED test for it.
</objective>
