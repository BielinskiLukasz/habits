| Dead-code investigation trap | `js/domain/waveAggregates.js` (`computeWaveAggregates`/`_countForHabit`) looks like the obvious place to fix Wave Board completion-rate bugs, but it has zero live callers outside tests. The real live path is `js/io/scoreSnapshots.js` → `score_snapshots` IDB store → `js/views/desktop/waveboard.js`. | advisory | Before debugging any Wave Board display number, grep for the actual caller chain from `waveboard.js` first — do not assume `waveAggregates.js` is reachable. |
| Cadence "still due" semantics summed per-day | `cadence.appliesToday()` intentionally stays `true` every day from a weekly/monthly period's start through the completion day (D-49/CADENCE-03, for Today-view show/hide). Any code that sums this flag across calendar days to build a completion denominator will overcount (1-7 instead of 1 per period). | advisory | For weekly/monthly cadence, count exactly one applicable occurrence per elapsed period (see `_computeS1Periodic` in `js/domain/scoring.js` and the new `_snapshotApplicability()` in `js/io/scoreSnapshots.js` for the correct pattern). Check `computeS2`/`computeS3` for the same latent gap if touched later. |
