  **createHabit:**
  - Writes: habits row, habit_versions row (effectiveFrom = startDate or today), events row
  - habits row fields: `{id: newId(), name, name_pl: null, wave, status:'active', cadence, targetType, target, stages:[], currentStageIndex:0, stageStartedAt: startDate, masteryThresholdOverride:null, masteryWindowOverride:null, createdAt:startDate, startDate, lastCompletedDate:null}`
  - habit_versions row: `{habitId: id, effectiveFrom: startDate, name, name_pl:null, cadence, targetType, target, stages:[]}`
  - inverse: `{type:'deleteHabit', payload:{habitId}}` — used for undo; deleteHabit handler not in this plan but the inverse shape must be correct
  - broadcastKeys: `{habitId}`

  **editHabit:**
  - Reads current habit row from repo to get `id`, existing fields
  - Writes: updated habits row (with new name/cadence/targetType/stages/etc.), NEW habit_versions row (effectiveFrom = today), events row
  - Does NOT write any logs row — existing logs are untouched (NFR-10)
  - inverse: `{type:'restoreHabitVersion', payload:{habitId, priorVersion}}` — priorVersion captured at write time
  - broadcastKeys: `{habitId}`
  </behavior>
