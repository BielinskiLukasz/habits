     b. `const logsForDate = await repo.getLogsForDate(date)`.
     c. `const allHabits = await repo.getAllHabits()`.
     d. For each habit: if `habit.createdAt > date` skip (habit didn't exist). Get `const version = await repo.getHabitVersionAtDate(habit.id, date)` — if undefined, skip.      e. Find `const log = logsForDate.find(l => l.habitId === habit.id)`.

     g. Mount header `buildHistoryHeader(displayDate, date < todayLocal())`, bulk action bar `buildBulkActionBar()`, then all applicable habit rows.

        - `'prev-day'` → selectedDate = daysFrom(selectedDate, -1); render(selectedDate).
        - `'next-day'` → if selectedDate < todayLocal(): selectedDate = daysFrom(selectedDate, +1); render(selectedDate). (No future navigation.)

Actually re-read HISTORY-04: "mark all not-yet-completed habits as uncompleted" → write `completed:false`.
