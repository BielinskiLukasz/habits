## Context

### Wave-board data model (D-118)

The wave-board reads from `score_snapshots` for a date range (last 12 weeks) — NEVER calls `scoring.js` directly.

**Data sources:**
1. `repo.getAllHabits()` — for habit list and wave grouping
2. `score_snapshots` IDB range query: all rows where `date` is in `[twelveWeeksAgoYMD, todayYMD]`
   - Use `repo.runTx(['score_snapshots'], 'readonly', tx => tx.objectStore('score_snapshots').index('date').getAll(IDBKeyRange.bound(startDate, endDate)))` → returns array of snapshot rows
3. No `getSetting('scoringModel')` — wave-board ALWAYS uses S1 status (D-118, see UI-SPEC §Specifics)

**Cell value derivation** (D-118):
- For a (habit, week) cell:
  - Collect all days in that ISO week
  - For each day, find the snapshot row for that habit+day
  - If no snapshot rows exist for any applicable day: cell = N/A (grey)
  - Otherwise: cell = worst S1 status among all days with snapshots in that week
  - Status ordering (worst first): `Failing > At-risk > Watch > Healthy`

**ISO week utilities:**
- ISO week number: `getISOWeek(date)` — can be computed from JS Date: the week containing Thursday of the date's year is week 1
- Week label: `"W" + isoWeekNumber` (e.g., "W26")
- 12-week window: last 12 complete ISO weeks ending with the current week

**Grid structure** (UI-SPEC §Wave-board Heat-map Layout):
- Leftmost column: habit names (sticky: `position: sticky; left: 0`) — class `.waveboard-sticky-column`
- Week columns: one per ISO week (12 default), with week number as header
- Wave header rows: full-width row with wave name, no cells
- Cell class: `.waveboard-cell` + `.waveboard-cell--{status}` where status = healthy/watch/atrisk/failing/na
- Cell `title` attribute: `"{status} ({applicableDaysWithLogs}/{totalApplicableDays})"` or `"Not applicable"` (accessibility per NFR-07)

### Pure builders pattern (D-26)

`js/views/desktop/waveboard.js` exports:
- `buildWaveboardHeader({ weeks, showArchived })` — returns column headers row
- `buildWaveboardRows({ habitsByWave, cellData, weeks, showArchived })` — returns all body rows
- `mountWaveboard(parent, { repo, store })` — live DOM mount

`cellData`: `Map<habitId, Map<isoWeekKey, { status, applicable, completed }>>` where `isoWeekKey = 'W<year>-<week>'`

**ISO week helpers** (inline, not exported):

```javascript
/**
 * Returns ISO week number and year for a YYYY-MM-DD date string.
 * @param {string} dateYMD
 * @returns {{ year: number, week: number }}
 */
function getISOWeek(dateYMD) {
  const [y, m, d] = dateYMD.split('-').map(Number);
  const date = new Date(y, m - 1, d);
  // ISO 8601: week starts on Monday; week 1 contains January 4th
  const dayOfWeek = date.getDay() || 7; // Sunday=7
  date.setDate(date.getDate() + 4 - dayOfWeek); // Thursday of this week
  const yearStart = new Date(date.getFullYear(), 0, 1);
  const weekNum = Math.ceil(((date - yearStart) / 86400000 + 1) / 7);
  return { year: date.getFullYear(), week: weekNum };
}

function isoWeekKey(dateYMD) {
  const { year, week } = getISOWeek(dateYMD);
  return `${year}-W${String(week).padStart(2, '0')}`;
}

function isoWeekLabel(key) {
  // "2026-W26" → "W26"
  return 'W' + key.split('-W')[1];
}
```

**`buildWaveboardHeader({ weeks, showArchived })`:**
- `weeks`: `string[]` — array of `isoWeekKey` strings in chronological order (12 default)
- Returns `{ tag: 'tr', children: [ {tag:'th', attrs:{class:'waveboard-sticky-column'}, text:'Habit'}, ...weeks.map(w => {tag:'th', text: isoWeekLabel(w)}) ] }`

**`buildWaveboardRows({ habitsByWave, cellData, weeks, showArchived })`:**
- Returns `Array<element>` (array of `<tr>` objects)
- For each wave group: push a wave header `<tr class="analytics-wave-header"><td colspan={weeks.length+1}>{waveName}</td></tr>`
- For each habit in wave (skip archived if `!showArchived`):
  - Row class: `['waveboard-row', ...(habit.status === 'archived' ? ['analytics-row--archived'] : [])].join(' ')`
  - First cell: `<td class="waveboard-sticky-column">{habit.name}</td>`
  - One cell per week:
    - `const weekCell = cellData.get(habit.id)?.get(week)`
    - If no weekCell: `<td class="waveboard-cell waveboard-cell--na" title="Not applicable">` with text `""`
    - Otherwise: `<td class="waveboard-cell waveboard-cell--{statusSlug(weekCell.status)}" title="{weekCell.status} ({weekCell.completed}/{weekCell.applicable} days)">` with text `""`
    - Archived habit cells: force `--na` class for visual graying

**`mountWaveboard(parent, { repo, store })`:**
- Idempotency guard: `parent.dataset.mounted === 'waveboard'`
- "Show archived" toggle checkbox above the grid
- Data fetch:
  1. `const habits = await repo.getAllHabits()`
  2. Compute `startDate` = 12 ISO weeks back, `endDate` = today (YYYY-MM-DD)
  3. Fetch snapshots: `repo.runTx(['score_snapshots'], 'readonly', tx => tx.objectStore('score_snapshots').index('date').getAll(IDBKeyRange.bound(startDate, endDate)))`
  4. Build `cellData`:
     - For each snapshot row, compute `week = isoWeekKey(row.date)`
     - Build `cellData.get(row.habitId).get(week)` accumulating worst status
     - Status ordering for worst: `Failing` > `At-risk` > `Watch` > `Healthy` (map to numeric: Failing=4, At-risk=3, Watch=2, Healthy=1, null=0)
  5. Build `weeks` array: 12 ISO week keys ending at today's week, chronological
- Build `habitsByWave` sorted by wave number then habit creation order
- Render: `<div class="waveboard-container"><table class="waveboard-grid"><thead>[buildWaveboardHeader]</thead><tbody>[...buildWaveboardRows]</tbody></table></div>`
- Subscribe to `store.subscribe()` for reactivity (model switch does NOT affect wave-board display, but habit definition changes do)
- The `<div class="waveboard-container">` should have `style="overflow-x: auto"` — set via `setAttribute` not innerHTML

**Worst-status helper:**
```javascript
const STATUS_RANK = { Healthy: 1, Watch: 2, 'At-risk': 3, Failing: 4 };
function worstStatus(a, b) {
  return (STATUS_RANK[a] ?? 0) >= (STATUS_RANK[b] ?? 0) ? a : b;
}
```
