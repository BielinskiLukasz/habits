## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| File download | Blob creation → browser download |
| File upload | user-selected JSON file → Blob → FileReader → JSON.parse |
| Cross-tab communication | BroadcastChannel('habits') message |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-10 | Tampering | Blob download | accept | User downloads their own data; stored on their device |
| T-05-11 | Tampering | File upload + JSON.parse | mitigate | D-99 schema validation rejects unknown versions; JSON.parse is safe by default (no proto pollution) |
| T-05-12 | Information Disclosure | CSV in Excel | accept | CSV is user-controlled export; stored on their device |
| T-05-13 | Denial of Service | File picker | accept | No upload size limit; user controls file size; if needed, add 50MB sanity check post-v1 |

</threat_model>
