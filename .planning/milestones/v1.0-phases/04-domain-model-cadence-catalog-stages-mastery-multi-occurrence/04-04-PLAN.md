  <behavior>
**`computeWaveAggregates(waveNumber, habits, logs, today, ctx)` — returns aggregate metrics for one wave**

Parameters:
- `waveNumber` — integer (0..9, extensible)
- `habits` — all habit rows (filtered internally to `h.wave === waveNumber`)
- `logs` — all log rows relevant to the wave (passed from outside; no IDB inside)
- `today` — YYYY-MM-DD evaluation date
- `ctx` — `{appliesToday: fn, weekStart: string, weekCompletions: fn, monthCompletions: fn, globalThreshold: number, globalWindow: number, streakThreshold?: number, atRiskSlipRatio?: number}` — `streakThreshold` defaults to 80 (% of applicable habits completed on a day), `atRiskSlipRatio` defaults to 0.5 (50% of habits slipping = at-risk)

Returns:
```
{
  waveNumber: number,
  habitCount: number,
  statusCounts: {active: number, mastered: number, archived: number},
  completionPct: number,        // applicable+completed / total-applicable × 100 over all time
  longestStreak: number,        // consecutive days where >= streakThreshold% of applicable habits completed
  currentStreak: number,        // streak ending today (0 if today is not a streak day)
  isAtRisk: boolean,            // true if >= atRiskSlipRatio fraction of active habits are slipping
}
```

**Test cases:**

Empty wave (no habits belong to it):
- `computeWaveAggregates(99, [], [], '2026-06-04', ctx)` → `{habitCount: 0, statusCounts: {active:0,mastered:0,archived:0}, completionPct: 0, longestStreak: 0, currentStreak: 0, isAtRisk: false}`

Status counts:
- Wave has 3 active, 2 mastered, 1 archived habit → `{statusCounts: {active:3, mastered:2, archived:1}, habitCount:6}`
- `mastered` is determined by `ctx.isMastered(habit)` callback (boolean injected by caller from mastery.js)

Completion %:
- 2 daily habits in wave, 5 days of logs: habit A completed 4/5 applicable, habit B completed 3/5 → `completionPct = Math.round((7/10)*100)` = 70
- Active + mastered habits count; archived habits excluded from completion %

Longest streak (streakThreshold default 80%):
- 3 daily habits in wave; for 5 consecutive days all 3 completed → longestStreak = 5
- Day 6: only 1/3 completed (33% < 80%) → streak breaks at 5
- If 5 days of streak then 2 days off then 3 more → longestStreak = 5, currentStreak = 3

At-risk indicator (atRiskSlipRatio default 0.5):
- 4 active habits, 3 have completion < threshold over rolling window → 75% slipping >= 50% → `{isAtRisk: true}`
- 2/4 slipping = 50% >= 50% → `{isAtRisk: true}` (boundary: >= atRiskSlipRatio, not >)
- 1/4 slipping = 25% < 50% → `{isAtRisk: false}`

Mastered habits counted in statusCounts but excluded from isAtRisk denominator (mastered = graduated, not slipping):
- 2 active + 2 mastered: isAtRisk looks at only the 2 active habits
  </behavior>

  <implementation>
File: `js/domain/waveAggregates.js`

Header: `/** @file Wave-level aggregate metrics (WAVE-01..06, D-83 wave data structure). */`

Imports: `parseLocalYMD`, `daysBetween`, `daysFrom` from `../util/date.js`.

`computeWaveAggregates(waveNumber, habits, logs, today, ctx)`:

1. **Filter habits to wave**: `waveHabits = habits.filter(h => h.wave === waveNumber)`.
2. **Status counts**: iterate waveHabits; for mastered use `ctx.isMastered(habit)` (injected; returns boolean) for active habits; otherwise use `habit.status` field directly (`archived`, etc.).
3. **Completion %**: loop over all dates from the earliest habit's createdAt to today (or over available log dates). For each day: count active+mastered habits that apply (via `ctx.appliesToday`) AND have a completed log. Count total applicable. `completionPct = applicable>0 ? Math.round((completed/applicable)*100) : 0`. For efficiency, aggregate over logs directly rather than day-by-day loop (look up logs by date, check applicable).
4. **Streak computation**: determine which days the wave "met the streak threshold" — i.e., completed / applicable >= streakThreshold/100. Build a sorted array of such days; find the longest consecutive run via `daysBetween` between adjacent elements == 1.
5. **currentStreak**: walk backward from today counting consecutive streak-goal days.
6. **isAtRisk**: count active (non-mastered, non-archived) habits in wave where completion% over global window < ctx.globalThreshold. If count / activeCount >= atRiskSlipRatio → true.

Note: streak computation only needs to scan dates that have ANY log for the wave's habits — sparse scans are fine for P4.
  </implementation>
