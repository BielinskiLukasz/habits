  <behavior>
**Function signature:** `evaluateMastery(habit, logsForHabit, evaluationDate, ctx)`

Parameters:
- `habit` — IDB row shape: `{id, cadence, createdAt, targetType, target?, masteryThresholdOverride?, masteryWindowOverride?}`
- `logsForHabit` — array of log rows for this habit across all dates
- `evaluationDate` — YYYY-MM-DD (the date being evaluated, usually "today")
- `ctx` — `{globalThreshold: number, globalWindow: number, appliesToday: fn, weekStart: string, weekCompletions: fn, monthCompletions: fn}`

Returns: `{isMastered: boolean, isInGracePeriod: boolean, completedCount: number, applicableDayCount: number, percentage: number, threshold: number, windowDays: number}`

**Test cases:**

Grace period:
- `evaluateMastery({id:'h1', cadence:{type:'daily'}, createdAt:'2026-06-04'}, [], '2026-06-09', ctx70days90pct)` → `{isInGracePeriod: true, isMastered: false, completedCount: 0, applicableDayCount: 0, percentage: 0}`
- `evaluateMastery({...createdAt:'2026-06-04'}, [], '2026-06-11', ctx70days90pct)` → `{isInGracePeriod: false}` (day 7 = past grace)

Cadence-aware denominator (daily habit, 70-day window, 63/70 completed = 90%):
- Habit with `cadence:{type:'daily'}`, 70 logs all completed over 70 days, evaluation today → `{applicableDayCount: 70, completedCount: 70, percentage: 100, isMastered: true}`
- Habit with `cadence:{type:'day-of-week-subset', days:['mon','tue','wed','thu','fri']}` over 70 days → applicable ~= 50 days (not 70); 45 completed / 50 applicable = 90% → `{isMastered: true}`
- Same habit with 43/50 applicable completed = 86% → `{isMastered: false}` (below 90% threshold)

Per-habit override:
- Habit with `masteryThresholdOverride: 80, masteryWindowOverride: 30` with 25/30 applicable days completed = 83% → `{isMastered: true, threshold: 80, windowDays: 30}` (per-habit override used, not global 90/70)
- Habit with `masteryThresholdOverride: null` → uses global threshold

Log type dispatch:
- Binary: `log.completed === true` → counts as completed day
- Numeric: `log.count = 5, habit.target = 7` → does NOT count (5 < 7); `log.count = 7` → counts
- Numeric: `log.count = 0` (logged but zero) → does NOT count
- Slot-checklist: 3/7 slots checked → does NOT count as completed; 7/7 checked → counts
- Slot-checklist: `log.slots = [{checked:true},{checked:true}]` with 2 slots → counts (all checked)

Zero applicable days edge case:
- Habit with cadence that never applies in 70-day window (e.g., future-wave habit, all days non-applicable) → `{applicableDayCount: 0, percentage: 0, isMastered: false}`
  </behavior>

  <implementation>
File: `js/domain/mastery.js`

Header: `/** @file Pure mastery threshold evaluator (MASTERY-01..07, D-85..D-87). */`

Import: `isInGracePeriod` from `../util/date.js`. Import `parseLocalYMD`, `formatLocalYMD`, `daysFrom` from `../util/date.js`. Do NOT import `appliesToday` from cadence.js directly — it is injected via `ctx.appliesToday` to keep mastery.js pure and free of the ctx-wiring logic.

**LOG_COMPLETED dispatch table** (Pitfall 5 — no if-else chain on targetType):
```
const LOG_COMPLETED = {
  binary: (log, _habit) => log.completed === true,
  numeric: (log, habit) => (log.count ?? 0) >= (habit.target ?? 1),
  'slot-checklist': (log, _habit) => Array.isArray(log.slots) && log.slots.length > 0 && log.slots.every(s => s.checked),
};
```

`evaluateMastery` implementation steps:
1. Derive threshold and windowDays from per-habit override or global defaults.
2. Call `isInGracePeriod(habit.createdAt, evaluationDate)` — if true, return the zero-value grace period result.
3. Compute windowStart: `daysFrom(evaluationDate, -windowDays + 1)` (inclusive rolling window of windowDays days ending at evaluationDate).
4. Count applicable days: loop from windowStart to evaluationDate (inclusive); for each day call `ctx.appliesToday(habit, dayYMD, ctx)` — if true, increment applicableDayCount.
5. If applicableDayCount === 0, return zero-value non-grace result.
6. Count completed days: filter logsForHabit to those with date in [windowStart, evaluationDate]; for each, call `LOG_COMPLETED[habit.targetType ?? 'binary']?.(log, habit)`; increment completedCount if true.
7. Compute percentage: `Math.round((completedCount / applicableDayCount) * 100)`.
8. Return full result object.

Key constraint: window iteration uses `daysFrom(evaluationDate, -(windowDays-1-i))` or equivalent local-calendar step-by-setDate pattern; no raw millisecond arithmetic (Pitfall 4).
  </implementation>
