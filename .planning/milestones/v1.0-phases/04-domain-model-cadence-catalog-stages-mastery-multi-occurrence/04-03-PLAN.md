  <behavior>
**`evaluateStageTriggers(habit, date, ctx)` — returns `{shouldAdvance, nextStageIndex, triggeredBy}` or `{shouldAdvance: false}`**

Parameters:
- `habit` — `{id, stages: [{label, target, allowManual?, targetWeekDate?, advanceAfterDays?, advanceAfterDaysThreshold?}, ...], currentStageIndex: number, stageStartedAt: string}`
- `date` — YYYY-MM-DD evaluation date (today or the log date)
- `ctx` — `{triggerType?: 'manual', completionPercentage?: number}` — manual trigger context + completion % for the threshold variant

Returns: `{shouldAdvance: boolean, nextStageIndex: number, triggeredBy: string|null}`

Behavior cases:

Already at last stage:
- `evaluateStageTriggers({stages:[{...}], currentStageIndex:0}, date, ctx)` with 1 stage → `{shouldAdvance: false}` (nothing to advance to)

Manual trigger:
- Stage has `allowManual: true`, `ctx.triggerType === 'manual'` → `{shouldAdvance: true, nextStageIndex: 1, triggeredBy: 'manual'}`
- Stage has `allowManual: true`, `ctx.triggerType !== 'manual'` → manual trigger does NOT fire (only fires when user explicitly taps)
- Stage has `allowManual: false` (or undefined), `ctx.triggerType === 'manual'` → `{shouldAdvance: false}` (manual not enabled for this stage)

Scheduled-by-week trigger (targetWeekDate is the Monday of the target week in YYYY-MM-DD):
- Stage has `targetWeekDate: '2026-06-01'` (Monday), evaluated on `'2026-06-01'` → fires (on the Monday)
- Stage has `targetWeekDate: '2026-06-01'`, evaluated on `'2026-06-03'` → fires (Wednesday of same week, we passed the week start)
- Stage has `targetWeekDate: '2026-06-01'`, evaluated on `'2026-05-31'` → does NOT fire (before target week Monday)
- The check is: `date >= stage.targetWeekDate` (string comparison safe for YYYY-MM-DD)

After-N-days unconditional:
- `habit.stageStartedAt = '2026-05-01'`, `stage.advanceAfterDays = 30`, `date = '2026-05-31'` → daysBetween('2026-05-01','2026-05-31') = 30 → fires
- `date = '2026-05-30'` → 29 days → does NOT fire
- `stage.advanceAfterDays = 30`, `date = '2026-06-15'` → 45 days → fires (past threshold)

After-N-days with C% threshold:
- `stage.advanceAfterDays = 30, stage.advanceAfterDaysThreshold = 80` (%), `ctx.completionPercentage = 85`, 30 days elapsed → fires (BOTH met)
- `ctx.completionPercentage = 70` → does NOT fire (completion below 80%)
- days not yet elapsed (e.g., 25 days) → does NOT fire even if completion is 90%

OR composition — any single trigger firing = advance:
- Habit has `allowManual: true` AND `advanceAfterDays: 30`; only 25 days elapsed; `ctx.triggerType !== 'manual'` → `{shouldAdvance: false}` (neither fires)
- Same habit, 25 days elapsed, `ctx.triggerType === 'manual'` → `{shouldAdvance: true, triggeredBy: 'manual'}` (manual fires even though days didn't)
- Same habit, 30 days elapsed, no manual tap → `{shouldAdvance: true, triggeredBy: 'after-n-days'}` (days fires without manual)
- Same habit, 30 days elapsed AND manual tap → `{shouldAdvance: true, triggeredBy: 'manual'}` (first trigger wins; both are valid)

**`demoteStage(habit)` — returns `{newStageIndex: number}`**
- `demoteStage({currentStageIndex: 2})` → `{newStageIndex: 1}`
- `demoteStage({currentStageIndex: 1})` → `{newStageIndex: 0}`
- `demoteStage({currentStageIndex: 0})` → `{newStageIndex: 0}` (cannot go below 0)
  </behavior>

**TRIGGER_CHECKS** dispatch array (Anti-Pattern 4 extended — use array not table because triggers are evaluated in order, first truthy wins for triggeredBy, but all must be evaluated):

```
const TRIGGER_CHECKS = [
  { name: 'manual',              check: (stage, _h, _d, ctx) => stage.allowManual && ctx.triggerType === 'manual' },
  { name: 'scheduled-by-week',   check: (stage, _h, d, _ctx) => stage.targetWeekDate != null && d >= stage.targetWeekDate },
  { name: 'after-n-days',        check: (stage, h, d, _ctx) => stage.advanceAfterDays != null && !stage.advanceAfterDaysThreshold && daysBetween(h.stageStartedAt, d) >= stage.advanceAfterDays },
  { name: 'after-n-days-with-threshold', check: (stage, h, d, ctx) => stage.advanceAfterDays != null && stage.advanceAfterDaysThreshold != null && daysBetween(h.stageStartedAt, d) >= stage.advanceAfterDays && (ctx.completionPercentage ?? 0) >= stage.advanceAfterDaysThreshold },
];
```

`evaluateStageTriggers` logic:
1. If `habit.currentStageIndex >= habit.stages.length - 1` → return `{shouldAdvance: false, nextStageIndex: habit.currentStageIndex, triggeredBy: null}` (already at last stage).
2. Get `stage = habit.stages[habit.currentStageIndex]`.
3. Loop through TRIGGER_CHECKS array; for each, call `check(stage, habit, date, ctx)`. If any returns truthy, record `triggeredBy = entry.name` and break.
4. If triggeredBy is non-null: return `{shouldAdvance: true, nextStageIndex: habit.currentStageIndex + 1, triggeredBy}`.
5. Else: return `{shouldAdvance: false, nextStageIndex: habit.currentStageIndex, triggeredBy: null}`.

`demoteStage(habit)`:
- Return `{newStageIndex: Math.max(0, (habit.currentStageIndex ?? 0) - 1)}`.
