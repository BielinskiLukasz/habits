  `export function mountCatalog(parent, {repo, store})`:
  1. Read all habits: `const habits = await repo.getAllHabits()` (or store cache via `store.getCachedHabits()`).
  2. For each habit, compute masteryState: `evaluateMastery(habit, logs, today, ctx)` where logs come from a date-range query for the rolling window. Use `store.getCachedHabits()` if available (Phase 3 cache already has habits).
  3. Render catalog header via `buildCatalogHeader()`.
  4. Sort habits: active first, then archived; within each group sort by wave asc then creation order.
  5. Render each habit via `buildHabitListItem(habit, masteryState)`.
  6. Wire action handlers via `mount()` actions map:
     - `'create'` → open create panel (render `buildCreatePanel(todayLocal())` below the header, or replace the habit list area)
     - `'edit'` → open edit panel for the clicked habit (render `buildEditPanel(habit)` inline)
     - `'archive'` → `apply({type:'archiveHabit', payload:{habitId: el.dataset.habitId}})` then re-render
     - `'restore'` → `apply({type:'restoreHabit', payload:{habitId}})` then re-render
     - `'advance-stage'` → `apply({type:'advanceStage', payload:{habitId, triggerType:'manual'}})` then re-render
     - `'save-edit'` → collect form fields from edit panel, `apply({type:'editHabit', payload: {...fields}})` then close panel + re-render
     - `'save-create'` → collect form fields from create panel, `apply({type:'createHabit', payload: {...fields}})` then close panel + re-render
     - `'cancel-edit'` / `'cancel-create'` → close panel, re-render habit list
     - `'add-stage'` → add a new stage row to the stages list in the open edit/create panel
  7. Subscribe to `store.subscribe(render)` for live re-renders (same pattern as today.js).

  XSS safety: all habit names rendered via `textContent` (D-78 grep gate). No innerHTML anywhere.
  Touch targets: all interactive buttons >= 44×44px (D-79, NFR-06).
