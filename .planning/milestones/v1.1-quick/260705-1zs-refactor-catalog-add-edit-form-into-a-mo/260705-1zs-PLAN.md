<objective>
Wrap the catalog Add/Edit panel in a native `<dialog>` modal overlay instead of an inline card injected into the catalog section. The panel builders (buildCreatePanel, buildEditPanel) and all form logic are unchanged — only the container mount point and open/close calls change.

Purpose: The form is long (name, wave, cadence, stages, mastery) — surfacing it inline pushes the habit list out of view and makes Save/Cancel hard to reach on mobile. A centered modal overlay keeps the list visible in context and is scroll-contained.

Output: `<dialog id="catalog-modal">` in index.html, modal overlay CSS in catalog.css, updated open/close wiring in catalog.js.
</objective>
