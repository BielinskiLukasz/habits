# Quick Task 260705-0bq: Swap Deprecated Meta Tag

## Context

`<meta name="apple-mobile-web-app-capable" content="yes">` is deprecated since Safari 17.
The modern replacement is the Web App Manifest `"display": "standalone"` — already present in `manifest.json`.

Both `index.html` and `desktop.html` carry this tag on line 9.

## Tasks

### T1: Remove deprecated meta tag from index.html and desktop.html

- **files**: `index.html`, `desktop.html`
- **action**: Delete the `<meta name="apple-mobile-web-app-capable" content="yes">` line from both files
- **verify**: Neither file contains `apple-mobile-web-app-capable` after the change
- **done**: Both files edited, one atomic commit
