# Quick Task 260828-00l: Add Full EN/PL i18n to Nawyki Habits App Summary

Zero-dependency EN/PL i18n wired across all 9 view builder files with a localStorage-backed locale module and a Language card in Settings for runtime switching.

## What Was Built

### Task 1 — i18n Module

- `js/i18n/en.js` — full English locale dictionary (~70 keys covering nav, today, catalog, history, settings, desktop views)
- `js/i18n/pl.js` — full Polish locale dictionary mirroring all keys
- `js/i18n/index.js` — exports `getLang()`, `setLang(lang)`, `t(key, subs?)`, `_resetLangForTest()`. Reads from `localStorage('habits-lang')` at init; defaults to `'en'`. Supports `{placeholder}` substitution syntax.
- `tests/unit/i18n.test.js` — 9 tests covering locale switching, fallback chain, substitution, and test reset

### Task 2 — View Wiring

All 9 view builder files had hardcoded user-facing strings replaced with `t()` calls:

- **today/builders.js** — nav labels, date header, check-in row labels; PL_WEEKDAY_SHORT / PL_MONTH_SHORT arrays for Polish date formatting
- **history/builders.js** — nav arrows, Jump to date, Toggle, Mark all buttons
- **settings/builders.js** — all 7 card headings and all user-facing labels; new `buildLanguageCard()` export
- **settings.js** — `setLang` action, `wireLangSelect()` change-listener wiring, Language card mounted first
- **catalog/builders.js** — Catalog title, New Habit button, wave badge, status/mastered badges, all panel form labels; `displayName` uses `name_pl` when lang is `'pl'`
- **desktop/analytics.js** — Scoring Model label, Habit column header, Stage cell, Mastered cell
- **desktop/planning.js** — Wave/Habit column header, empty-state h2 and hint paragraph
- **desktop/waveboard.js** — Habit column header
- **desktop/wavePlanning.js** — Upcoming/No Data badges, Promote button, Scheduled h3, empty wave message
