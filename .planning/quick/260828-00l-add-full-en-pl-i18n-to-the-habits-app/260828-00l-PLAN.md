--- js/i18n/index.js ---

File header: @file i18n module for Nawyki — t(key, subs?), getLang(), setLang(lang).
Reads lang preference from localStorage('habits-lang') on module init; defaults to 'en'
when localStorage is absent (Node test environment) or value is invalid. setLang() writes
to localStorage and calls location.reload() — simple full-page refresh strategy avoids
partial-update bugs. No dynamic imports; en.js and pl.js are static imports at module
load time.

Imports: `import { EN } from './en.js';` and `import { PL } from './pl.js';`

Module-level setup:
```
const LOCALES = { en: EN, pl: PL };
const VALID = new Set(Object.keys(LOCALES));
const _storage = typeof localStorage !== 'undefined' ? localStorage : null;
let _lang = VALID.has(_storage?.getItem('habits-lang') ?? '') ? _storage.getItem('habits-lang') : 'en';
```

Exports (all named exports):

`getLang()` — returns _lang string ('en' | 'pl').
JSDoc: @returns {'en'|'pl'}

`setLang(lang)` — validates lang is in VALID; if not, silently returns. Writes to
_storage?.setItem('habits-lang', lang). Calls (globalThis.location?.reload?.()). If
location is absent (Node), does nothing after the storage write.
JSDoc: @param {'en'|'pl'} lang

`t(key, subs)` — looks up key in LOCALES[_lang]; falls back to LOCALES['en'][key] if not
found in current locale; falls back to key itself if still not found (defensive). If `subs`
is provided (a plain object), replaces `{name}` placeholders in the result string using a
simple replace loop: `result = result.replace('{' + k + '}', String(subs[k]))` for each
key k in subs. Returns the final string.
JSDoc: @param {string} key  @param {Record<string,string|number>} [subs]  @returns {string}
