# Quick Task 260705-t13b: Apply completion CSS class to multi-occurrence rows

## Goal

T13b from Phase 06 UAT: Completed multi-occurrence habits (numeric + slot) show green
counter but no strikethrough/muted treatment. Binary habits DO get strikethrough and
muted appearance via `today-row--completed`. Fix: apply the same visual completion
treatment to numeric and slot rows.

## Root Cause

`buildNumericRow` and `buildSlotRow` (js/views/today/builders.js) emit `habit-row--complete`
when complete — but that class has no CSS in `today.css`. Only `today-row--completed` has
the muted (`opacity: 0.55`) treatment. The name span never gets `today-row-name--completed`
(strikethrough) for these row types.

## Tasks

### T1: RED tests for today-row--completed on numeric/slot rows

**File:** `tests/unit/builders.today.numeric.test.js`

Add two failing tests:
- `buildNumericRow` complete row also has `today-row--completed` class
- `buildSlotRow` complete row also has `today-row--completed` class

**Verify:** `node --test tests/unit/builders.today.numeric.test.js` → 2 new failures

### T2: Apply today-row--completed + strikethrough to numeric/slot rows

**File:** `js/views/today/builders.js`

1. `buildNumericRow` (line 208): when `isComplete`, class becomes
   `'today-row today-row--numeric habit-row--complete today-row--completed'`
2. `buildNumericRow` name span: when `isComplete`, class becomes
   `'today-row-name today-row-name--completed'`
3. `buildSlotRow` (line 299): when `isComplete`, class becomes
   `'today-row today-row--slot habit-row--complete today-row--completed'`
4. `buildSlotRow` name span: when `isComplete`, class becomes
   `'today-row-name today-row-name--completed'`

**Verify:** `node --test tests/unit/builders.today.numeric.test.js` → all pass

- `today-row--completed` present on numeric row `<li>` when `count >= target`

- `habit-row--complete` still present (used by `history.css` + existing tests)
