# Quick Plan: History Screen Swipe UX

## Goal

Add the same 4-state swipe UX to the History screen that the Today view has — swipe-right marks completed, swipe-left reveals Skip/Fail action panel.

## Approach

1. **`builders.js`** — Update `buildHistoryHabitRow` to wrap content in `.history-row__slide` + add `.today-row__actions` panel with skip/fail buttons. Add 4-state status display (✓ / ↷ / ✕ / –) and row state classes (`history-habit-row--completed`, `--skipped`, `--failed`).

2. **`history.css`** — Change `.history-habit-row` to `position:relative; overflow:hidden` (move flex to `.history-row__slide`). Add slide layer styles and completion state modifier rules.

3. **`history.js`** — Add module-level swipe state (`_openSwipeRow`, `_swipeEl`, `_swipeStartX`). Create closure-based pointer event handlers inside `mountHistory` so they capture `selectedDate` by reference. Wire on `listEl`. Handle `history-swipe-skip` and `history-swipe-fail` actions. Fix pre-existing `toggle-log` bug (was checking `currentLog?.completed === true`; 4-state logs use `status` field).

## Reuse

CSS classes `today-row__actions`, `today-row__action`, `today-row__action--skip`, `today-row__action--fail` are from `today.css` (globally loaded) — no duplication.
