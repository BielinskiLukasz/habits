**js/views/desktop/sidebar.js** — new module. Follow project conventions: JSDoc file header,
exported function with JSDoc, no `.innerHTML`, no direct `indexedDB` calls, DI-compatible.

```
/**
 * @file Desktop sidebar collapse/expand toggle — persists to localStorage.
 *
 * Manages the `.desktop-sidebar--collapsed` modifier on the sidebar nav element
 * and keeps nav links out of keyboard tab order while collapsed.
 * Preference persisted at key `habits:sidebar-collapsed` in localStorage.
 */
```

Export one function:

```
/**
 * Mount the sidebar toggle button behaviour. Reads stored preference, applies
 * initial state, and wires click + keyboard activation on the toggle button.
 *
 * @param {HTMLElement} sidebarEl - The .desktop-sidebar nav element.
 * @returns {void}
 */
export function mountSidebarToggle(sidebarEl) { ... }
```

Implementation steps inside `mountSidebarToggle`:

1. Locate the toggle button: `const btn = sidebarEl.querySelector('#sidebar-toggle');`
   If not found, return early (defensive guard).

2. Locate all nav links: `const links = sidebarEl.querySelectorAll('.desktop-sidebar-link');`

3. Read stored preference:
   `const stored = localStorage.getItem('habits:sidebar-collapsed');`
   `let collapsed = stored === 'true';`

4. Define `applyState(isCollapsed)`:
   - Toggle class: `sidebarEl.classList.toggle('desktop-sidebar--collapsed', isCollapsed);`
   - Update button aria: `btn.setAttribute('aria-expanded', String(!isCollapsed));`
   - Update button label: `btn.setAttribute('aria-label', isCollapsed ? 'Expand sidebar' : 'Collapse sidebar');`
   - Update icon text (textContent of the `<span.desktop-sidebar-toggle-icon>`):
     `const icon = btn.querySelector('.desktop-sidebar-toggle-icon');`
     `if (icon) icon.textContent = isCollapsed ? '\u203A' : '\u2039';`
     (`›` when collapsed = click to expand; `‹` when expanded = click to collapse.)
   - Set tabindex on links:
     `for (const link of links) {`
     `  if (isCollapsed) link.setAttribute('tabindex', '-1');`
     `  else link.removeAttribute('tabindex');`
     `}`

5. Apply initial state without persisting: `applyState(collapsed);`

6. Wire click:
   `btn.addEventListener('click', () => {`
   `  collapsed = !collapsed;`
   `  applyState(collapsed);`
   `  localStorage.setItem('habits:sidebar-collapsed', String(collapsed));`
   `});`

No `switch` statements (Anti-Pattern 4). No `innerHTML` (D-78).
